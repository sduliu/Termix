# Termix personal Windows client

## Platform

Web UI in an Electron Windows x64 desktop application.

## Users and tasks

One person managing a small number of servers. Hosts should be directly
accessible without requiring Tailscale folders. Preserve SSH, remote desktops,
files, credentials, connections, snippets and configured AI capabilities.

## Constraints

Keep existing backend contracts and server permission enforcement. Never embed
credentials in previews, source or logs. Build unsigned NSIS installers on
standard GitHub-hosted Windows runners. Product name and icons remain Termix
pending a separate branding decision.
