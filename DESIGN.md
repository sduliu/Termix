# Operations console

User selected direction C from preview/ui-variants.html: dark operations
workspace, clear host state, real activity, direct and batch actions.

Mode: Operate. Use existing theme tokens, a restrained blue action accent,
green/amber/red status dots with text, system UI typography and monospace only
for addresses or terminal content. No invented monitoring values.

Composition: labeled app navigation, unframed title and status filter strip,
searchable root-level host table, right-hand activity list. Stack activity below
hosts on narrow viewports. Tables may scroll internally on phones. Preserve
existing configurable dashboard as a secondary view. Batch connection acts
only on visible selected hosts and respects enabled connection protocols.
